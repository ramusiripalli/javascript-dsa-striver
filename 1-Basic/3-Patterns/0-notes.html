Rules for Solving Patterns

  1. Figure out the number of lines to be printed and write your outer loop on it.

    Determine how many rows (lines) the pattern will have. Use this number to control the outer loop.

    Example: If the pattern has 5 rows, your outer loop will run 5 times.

  2. Figure out what is happening at every line and try to connect with the outer loop.

    Analyze what is being printed in each row (e.g., stars, numbers, etc.) and connect it to the outer loop variable.

    If possible, write your inner loop based on this logic.

  3. Execute print when needed.

    Use console.log() or process.stdout.write() to print the pattern at the appropriate time.

  4. Observe symmetry (optional).

    Check if the pattern is symmetric. If it is, you can optimize your code by leveraging symmetry.

Note: These rules are general guidelines. Practice is key to mastering pattern-solving!
